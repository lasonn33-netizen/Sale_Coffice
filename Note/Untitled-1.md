# Coffice Laravel API/docs## Windows prerequisitesInstall PHP 8.5+ and Composer before running Laravel. The easiest Windows option is[XAMPP](https://www.apachefriends.org/) for PHP, followed by[Composer](https://getcomposer.org/download/). Add the PHP folder to Windows PATH,for example `C:\xampp\php`, then restart VS Code.Verify the installation:```powershellphp -vcomposer --version```If either command is not recognized, Laravel cannot run until that installation orPATH issue is fixed.## Setup with PostgreSQLCreate a PostgreSQL database named `coffice`, then update `.env` with your PostgreSQL username and password.```bashcomposer installcopy .env.example .envphp artisan key:generatephp artisan migrate --seedphp artisan serve```The API is available under `http://localhost:8000/api/v1`. The seeded administrator is `admin` / `password`; change this before production use.Set `VITE_API_BASE_URL=http://localhost:8000/api/v1` in each frontend application.Public endpoints are product/category reads and registration/login. Catalog management, users, order status changes, and deletion require an administrator bearer token.```DB_CONNECTION=pgsqlDB_HOST=127.0.0.1DB_PORT=5432DB_DATABASE=cofficeDB_USERNAME=postgresDB_PASSWORD=NewPassword123```Laravel 12.71.0PHP 8.5.12Composer 2.11.1Database: pgsql
